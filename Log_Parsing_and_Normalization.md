# Log Parsing & Normalization

## Understanding Log Parsing & Normalization
Log parsing and normalization are essential steps in SIEM workflows. They transform raw, unstructured logs into structured, standardized, and searchable security data. This process ensures that analysts can detect threats, run queries, and correlate events across diverse systems effectively.

---

## Raw Logs
Raw logs are the unprocessed records generated by systems, applications, and devices.  
- They contain information such as timestamps, IP addresses, usernames, and actions.  
- Raw logs are often inconsistent, with different formats depending on the source.  
- For example, a firewall log may look different from a Windows event log or a web server log.  
- While raw logs provide valuable data, they are difficult to analyze without further processing.  

---

## Structured Data
Structured data is created when raw logs are parsed into clearly defined fields.  
- Parsing extracts elements such as `source.ip`, `destination.port`, `event.type`, and `timestamp`.  
- This makes the data machine‑readable and easier to query.  
- Structured data allows analysts to filter, sort, and search logs quickly.  
- Without structuring, logs remain as plain text, which is inefficient for security monitoring.  

---

## Data Normalization
Data normalization ensures that structured fields from different sources follow a consistent format.  
- Different systems may use different names for the same field (e.g., `src_ip`, `SourceAddress`, `client_ip`).  
- Normalization translates these into a standard schema such as `source.ip`.  
- This consistency allows SIEM rules, dashboards, and searches to work across all data sources.  
- Normalization is critical for correlation, since it enables the SIEM to compare events from different systems accurately.  

---

## Event Categorization
Event categorization groups normalized data into meaningful categories.  
- Examples include authentication events, network traffic, file access, or system errors.  
- Categorization helps analysts focus on specific types of activity, such as failed logins or suspicious downloads.  
- It also supports compliance reporting by organizing events into categories required by regulations.  
- By categorizing events, SIEM reduces noise and highlights the most relevant security activities.  

---

## Searchable Security Data
The final outcome of parsing, normalization, and categorization is searchable security data.  
- Analysts can run queries across millions of events using consistent field names.  
- Searchable data supports dashboards, threat hunting, and forensic investigations.  
- It enables correlation rules to detect complex attack patterns across multiple systems.  
- Searchable security data transforms raw logs into actionable intelligence for SOC teams.  

---

## Key Takeaway
Log parsing and normalization convert raw, inconsistent logs into structured, standardized, and categorized data. This process ensures that security teams can search, analyze, and correlate events effectively, turning raw information into meaningful insights for threat detection and investigation.
